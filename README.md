# Jogo Elemental (nome provisório: Athanor)

Jogo idle de navegador e celular. Você coleciona bichinhos elementais num gacha, evolui e funde eles, e eles trabalham sozinhos para você construir uma cidade bonita e livre num terreno que cresce.

Tudo o que já foi decidido está em [docs/design.md](docs/design.md). Os três iniciais (Sol, Lua e Sombra) e o estilo de arte aprovado estão em [docs/iniciais.md](docs/iniciais.md). Esse segundo documento é mais recente e prevalece onde os dois divergem. A lista de jogos para pesquisar está em [docs/inspiracoes.md](docs/inspiracoes.md).
